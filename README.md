# SCION-X_TLM_Explorer
SCION-X Telemetry Mapping, SatNOGS Incremental Download and Decoding Tools

Windows 64 位元遙測繪圖與資料更新工具。

1. 執行 SCIONX_TLM_Setup.exe，首次安裝需連網下載 MATLAB Runtime R2026a。
2. 關閉程式，將本儲存庫的 data 資料夾複製到安裝後 EXE 同層，
   取代初始 data，以使用最新 Excel 與下載紀錄。
3. 首次使用「更新繪圖參數來源」時，設定 SatNOGS URL 與自己的 API Key。
4. 更新成功後自動刪除 OGG 暫存，保留 Excel 與處理清單。
